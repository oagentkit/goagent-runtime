# runtime 是什么

**goagent-runtime 是 [goagent-kernel](https://github.com/yi-nology/goagent-kernel) 的装配层。**

kernel 提供的是「确定性机制」——状态机、幂等、栅栏、预算、恢复——这些机制能保证一个 Agent 在中断、重试、并发下**不重不漏**，但它们是一个个零件。runtime 把零件装成整车：你给一个模型接口、一组工具，就能 `Run` 起一个会话。

## 小白类比：外卖平台与骑手

| 类比 | 对应 |
|---|---|
| 你开的餐馆（只做菜） | **宿主产品**：只写提示词、工具、模型适配 |
| 外卖平台的调度系统 | **runtime**：接单、派单、跟踪、兜底 |
| 平台规则（一单不送两次、超时怎么判） | **kernel**：判据——幂等闸、预算守卫、恢复语义 |
| 道路与电动车 | **oagentkit / oekit**：上游原语 |

餐馆老板不需要懂调度算法，只需要把菜做好；同样，宿主不需要懂幂等键怎么铸造，只需要把工具注册对。

## 为什么它是独立仓库

1. **门禁隔离**：kernel 的门禁核心是「内核包不拖存储驱动」。装配层必须直接装配 SQLite/PG 驱动与事件面，放进来会把那条判据开口子。
2. **发版节奏不同**：Runtime 的 Beta/RC/1.0 是产品层节奏，与 kernel 的机制版各发各的。

## 一句实话（边界声明）

本仓提供装配层与参考实现，**不保证所有机制已组成可直接部署的高可用 Agent Runtime**；实际能力以各模板的集成测试证据为准。cluster 模板尚未提供——把未验证的机制固化成默认路径，比没有模板更糟。
