# ADR-0009 · 流式接缝走 push 回调 + 框架归并器

| 项 | 内容 |
|---|---|
| **状态** | 已采纳（Accepted） |
| **日期** | 2026-11-23（#11 收口） |
| **背景** | 宿主要保住 SSE 逐片体验，就得在模型适配器里写一座「Stream 聚合桥」：逐 chunk 循环、EOF 判定、错误上抛、**工具调用按 Index 归并**、**usage 累计**。v0.6.0 的 `ChatRequest.OnDelta` 把「逐片投递到事件面」搬进了框架（那是桥里最简单的一段），但**归并那一段仍留在每个宿主手里**——各写各的、各踩各的坑（归并错位、usage 重复计、片段顺序错）。issue #11 建议的解法是加一个拉取式 `Streamer` 接口（`ChatStream(ctx, req, sink)`），由框架归并。 |
| **决策** | ① **走 push 回调路线**：保留 `ChatRequest.OnDelta`，**不引入**拉取式 `Streamer`——两个形状并存时，宿主不知道该写哪种桥（两形状＝新的坑），且 push 路线已随 v0.6.0 发布；② **归并规则收进框架侧一份实现**：`chat.DeltaAggregator`（按 `Index` 归并工具调用、累计 usage、拼接文本），宿主用它拼响应；③ **承载面扩展**：`chat.Delta` 增加可选的 `ToolCall` 片段与 `Usage` 计量（可选字段 ⇒ 非流式宿主零改动，`chat.Model` 契约一字未改）；④ **流式增量是观测面**：Joint 形态下只即时广播、**不落事件行**（落进去会污染状态面，也会打破「一轮四事件」判据）。 |
| **后果** | ① 宿主侧的桥从 60~80 行降到十来行（只剩「把 SDK 的 chunk 搬成片段」+ EOF/错误上抛），且**归并与 usage 累加不再各写各的**——规则一份、判据一份（`chat/stream_test.go`）；② `chat.Model` 契约不变：老宿主照常编译，不支持流式的实现不调用回调即可；③ 联合提交形态（standalone / cluster）里流式增量不再静默消失（此前只在 `Emitter` 非 nil 时挂回调 ⇒ 事件随快照落库的形态里根本没有 delta）；④ Joint 形态下 delta 不入库 ⇒ 状态面事件数与增量无关，「一轮四事件」判据成立；⑤ **边界要写清**：cluster 形态没有本地总线 ⇒ 逐片体验需宿主自建跨副本通道（结果回传仍走事件面）——不假装支持。 |
| **依据** | runtime issue #11；仓内 `chat/stream.go`（承载面 + 归并器）、`agentloop/loop.go` 的 `emitDelta` 与挂载条件、`agentloop/loop_delta_joint_test.go`（Joint 形态：即时广播 + 不落事件行 + 状态面四事件不受影响）、`chat/stream_test.go`（归并判据）；[ADR-0003](/goagent-runtime/adr/ADR-0003-模型接缝只有-chat-Model.html)（窄接口纪律：接缝只加可选形态，不改契约）。 |

> **一句话结论**：流式接缝走 push 回调 + 框架归并器——宿主只产片段，归并规则归框架一份，增量是观测面不进状态面。

---

## 为什么不做拉取式 `Streamer`

| 维度 | push 回调（`OnDelta`，采纳） | 拉取式 `Streamer`（未采纳） |
|---|---|---|
| 宿主写法 | `req.OnDelta(d)` 一行 | 实现新接口 `ChatStream(ctx, req, sink)` |
| 形状数量 | 一种（已发布） | 两种并存 ⇒ 宿主不知道写哪种 |
| 破坏性 | 无（可选字段） | 新增接口面（可加，但多一条路要维护） |
| 归并位置 | 框架（`DeltaAggregator`） | 框架 |

两条路都能达成「宿主只产片段」；选 push 是因为**少一条路**，且它已随 v0.6.0 发布。
若将来要换轨（例如需要框架主动拉取以做背压），应在 v1.0 之前**统一换**并写 ADR，而不是把两条路长期并存。

## 增量的三条边界

1. **观测面**：不进检查点/预算/恢复语义，也不落状态面事件行（Joint 形态）；
2. **可丢**：总线广播非阻塞，订阅方缓冲满则丢弃并计数（观测面允许丢，状态面不允许）；
3. **原样**：事件载荷透传原始片段（kind/text + 工具片段 + 计量），**不归并**——归并是响应面的事（`DeltaAggregator`）。
