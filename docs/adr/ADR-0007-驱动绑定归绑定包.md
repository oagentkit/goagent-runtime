# ADR-0007 · 驱动绑定归绑定包

| 项 | 内容 |
|---|---|
| **状态** | 已采纳（Accepted） |
| **日期** | 2026-11-23（v0.6.1 拆分落地，#10 收口 / #12 选型红线） |
| **背景** | Go 的依赖是**包级**的：`storage` 一度把「判据面（`Provider` 契约 + 内存实现）」与「绑定胶水（`OpenSQLite` → `sqliteadapter`）」放在同一个包里，而 `sqliteadapter` 里有 `import _ "modernc.org/sqlite"`。⇒ 任何只想用内存面的宿主，只要 import 了 `storage`，modernc 驱动就进了链接面。而 `database/sql` 的驱动注册表是**进程级全局态**：宿主自己已链接一个同名注册 `"sqlite"` 的驱动（如 `github.com/glebarez/go-sqlite`，modernc 的 fork）时，同二进制 `init` 即 `panic: sql: Register called twice for driver sqlite`——应用一行业务代码都跑不到，报错还不指明是哪个包引进来的第二个驱动。bianque 接入时实弹过一次。 |
| **决策** | 判据面与绑定面**分包**：`storage` 只留契约与内存实现（**零驱动边**），SQLite 的 Provider 绑定落到 `storage/sqlitestore`；**驱动边只住在绑定包**——不 import 绑定包，就零驱动边。宿主按面 import：只要内存面就只 import `storage`。另加**机器判据** `make deps`：纯判据包的生产依赖面与测试依赖面都不得出现数据库驱动（`scripts/check-dep-edges.sh`）。 |
| **后果** | ① **破坏性变更**：`storage.OpenSQLite` / `storage.SQLite` 移除，宿主改用 `sqlitestore.Open`（pre-1.0 阶段的换轨）；② 宿主只要内存面 ⇒ 零驱动边，可与自带 SQLite 驱动共存；③ 宿主要真 SQLite 且自带同名驱动 ⇒ **不得** import 绑定包——这条选型红线写进 README 与 `sqliteadapter` 包文档（#12）；④ 纪律从「靠自觉」变成「机器判红」：同形面（有人在 `storage` 里再 import 一个驱动）当场被 `make deps` 与 CI 的依赖面门禁拦下。 |
| **依据** | runtime issue #10（现象与复现）、#12（选型红线）；bianque 双 driver 注册实弹；Go 包级依赖语义；仓内 `scripts/check-dep-edges.sh` 与 `storage/provider.go` 的零驱动边声明。 |

> **一句话结论**：驱动绑定归绑定包——判据面（`storage`）零驱动边，绑定面（`storage/sqlitestore`）才带驱动，宿主按面 import。

---

## 两种面，各自带什么

| 包 | 定位 | 依赖面 |
|---|---|---|
| `storage` | 判据面：`Provider` 契约 + 内存实现 + `JointCommitter` 能力面 | **零驱动**（生产与测试依赖面都无数据库驱动） |
| `storage/sqlitestore` | 绑定面：SQLite Provider 的绑定与生命周期 | 带 `modernc.org/sqlite`（经 `sqliteadapter` 参考实现） |
| `sqliteadapter` | 参考实现本体（自 kernel 迁入，判据套件同源） | 带 `modernc.org/sqlite` |

「参考实现要链驱动」是对的——它本来就是**落库的那一面**；错的是判据面被绑上。

## 机器判据（`make deps`）

纪律只写在散文里就会漂——本仓的判据必须是**可执行的**：

```bash
$ bash scripts/check-dep-edges.sh
✅ 依赖面门禁通过：./storage 的生产与测试依赖面均无数据库驱动
```

判据形态：逐个纯判据包取 `go list -deps`（生产面）与 `go list -deps -test`（测试面），
命中任一数据库驱动即判红；`go list` 跑不起来同样判红（判据跑不起来不许报绿）。
反向验证已做：往 `storage` 注入一行 `import _ "modernc.org/sqlite"` ⇒ 门禁判红并退出 1。

## 与 #12 的分工

#10 给**技术出路**（按面 import；绑定包可拆可换）；#12 给**选型红线**
（全二进制只允许一个驱动注册 `"sqlite"`，宿主自带同名驱动时的处置与排查线索）。
两条合起来才是完整约束：能拆的拆了，不能拆的写清楚。
